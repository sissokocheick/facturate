2. Politique de confidentialité

Principe : aucune donnée collectée

Facturate est une application 100 % locale. Les informations que vous saisissez (coordonnées, clients, montants) sont stockées exclusivement dans la mémoire de votre navigateur (stockage local, « localStorage ») sur votre appareil.

  • Aucune donnée n'est envoyée vers un serveur.
  • Aucun compte, aucune inscription, aucune authentification.
  • Aucun cookie de pistage n'est déposé.
  • Aucune donnée n'est cédée ni vendue à un tiers.

Conservation

Les brouillons restent enregistrés dans votre navigateur tant que vous ne les effacez pas. Vous pouvez les supprimer à tout moment via le bouton « Nouveau » ou en vidant les données de navigation de votre appareil.

Statistiques de fréquentation

Si l'outil est déployé avec un service de mesure d'audience, celui-ci ne collecte que des données agrégées anonymisées (pages vues), sans identification des personnes. Aucune donnée saisie dans les formulaires n'y est incluse.
